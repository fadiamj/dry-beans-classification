\# Dry Bean Classification



A university machine learning project focused on classifying dry bean varieties using data analysis and supervised machine learning.



\## Project Overview



The goal of this project is to explore a dry bean dataset, analyze its characteristics, and develop machine learning models to classify beans into their respective varieties.



The project uses a Jupyter Notebook to document the analysis, model development, and evaluation process. It also includes a written university project report.



\## Project Objectives



\- Explore and understand the dataset.

\- Analyze relationships and patterns in the data.

\- Develop and evaluate machine learning classification models.

\- Compare model performance using appropriate evaluation metrics.

\- Present the findings through visualizations and a written report.



\## Methods and Evaluation



The notebook includes classification work involving an Artificial Neural Network (ANN) and decision-tree analysis.



Model evaluation and visual analysis include:

\- Confusion matrix

\- F1-score analysis

\- Model performance visualizations



See the notebook and project report for the implementation details and actual experimental results.

\## Getting Started

&#x20;  ```bash

&#x20;  ```



2\. Navigate to the project directory:



&#x20;  ```bash

&#x20;  ```
